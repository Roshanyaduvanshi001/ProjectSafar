# SAFAR — Complete Product Specification

## 1. PRODUCT OVERVIEW

Create a complete, high-fidelity mobile travel companion app prototype called:

**SAFAR**

### Tagline

**"Set My Safar"**

The app should be designed as a premium, modern, trustworthy Indian travel companion that helps users plan, book, manage and complete their entire journey.

### Important

* This is a **MOBILE APP** prototype.
* Use a mobile frame size approximately **390 × 844 px**.
* Create a complete multi-screen functional prototype with consistent navigation and interactions.
* Do not create a generic travel booking website.
* The product should feel like a personal travel companion, not just a ticket booking app.

# 4. TYPOGRAPHY

Use **Inter** or a similar modern sans-serif font.

### Typography Hierarchy

* Large headings: 24–30px, bold
* Section headings: 18–22px, semibold
* Body: 14–16px
* Buttons: 15–16px, semibold
* Small labels: 12–14px

### Spacing

Use a consistent spacing scale:

`4, 8, 12, 16, 20, 24, 32, 40 px`

Use **20–24px horizontal screen padding**.
