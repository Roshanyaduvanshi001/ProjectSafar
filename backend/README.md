# SAFAR — Backend Service

## Overview

This directory is designated for the SAFAR backend REST API and WebSocket services.

## Planned Technology Stack (Phase 11)

- **Runtime**: Node.js (ES Modules)
- **Language**: TypeScript
- **Framework**: Express.js
- **Database**: MongoDB via Mongoose
- **Authentication**: JWT with refresh token rotation & bcrypt
- **Validation**: Zod schema validation
- **Documentation Reference**: [SAFAR_BACKEND_ARCHITECTURE.md](file:///e:/Safar/docs/SAFAR_BACKEND_ARCHITECTURE.md)

## Status

Architecture and API contracts have been established in Phase 10. Implementation will commence in Phase 11.
